## `~/about`

This repository is dedicated to **my personal writeups** for Capture The Flag competitions, cybersecurity labs, and challenges from a range of platforms. It is a place to keep my notes organized, revisit techniques, and share what I learn while exploring information security.

The collection is a work in progress: new writeups and platforms will be added over time. Each solution reflects my own approach and learning process; there may be other valid ways to solve the same challenge.

## `~/what-to-expect`

Depending on the challenge, a writeup may include:

- Challenge overview and objective
- Enumeration and analysis notes
- Step-by-step solution and reasoning
- Commands, scripts, and tools used
- Flags and key takeaways
- References for further learning

Directories may be organized by platform-specific categories, rooms, machines, labs, or competitions.

## `~/responsible-use`

These materials are provided for **educational purposes** and for use in authorized labs and CTF environments. Only apply the techniques described here to systems you own or have explicit permission to test. Please also respect each platform's rules, especially restrictions on publishing active competition solutions.

## `~/contributing`

This is a personal learning repository. Suggestions, corrections, and improvements are welcome through issues or pull requests.
